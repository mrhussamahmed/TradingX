## Amendment — Real backtest engine and candidate-family architecture landed

  minimal daily-bar research engine chosen in `ADR-0019`.
- The engine now models daily return in explicit phases: overnight
  close-to-open return on the existing position, rebalance at the next
  open, then intraday open-to-close return on the post-open portfolio.
- Added a smoke gate where engine-computed `SPY` buy-and-hold is
  compared against an identical engine-computed `SPY` benchmark path and
  must produce near-zero active CAGR and active Sharpe while preserving
  the benchmark max drawdown.

  and scaling primitives.

  pre-sized volatility-managed family and deleted the obsolete generic
  `src/tradingx/signals/vol_target.py` overlay so `sizing.py` is the
  sole owner of reusable non-pre-sized volatility targeting.
- Added `src/tradingx/sizing.py` for fixed `0.33` fractional Kelly plus
  generic `12%` annualized vol targeting on non-pre-sized strategies.
- Added `src/tradingx/signals/mean_revert.py` implementing
  SPY-residualized cross-sectional mean reversion with `t-1` discipline.
  The implementation rejects any tradable universe that includes the
  benchmark symbol.
- Updated `build_mandatory_candidate_registry()` so the mean-reversion
  candidate excludes `SPY` from its tradable universe while trend and
  `vol_target_spy` continue to trade their full universe.

  semantics and engine-computed benchmark smoke definition.

  path is rewired.

  The engine is real, but the gate-report path still only accepts
  synthetic close-series inputs, so producing new Gate 1 evidence would
  still be dishonest until that interface is replaced.
