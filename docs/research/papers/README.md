- **Pack A** — `Researching Autonomous Trading Bot Foundations.docx`
  (Google AI output, archived outside repo). 21 PDFs retrieved.

  24 PDFs retrieved; 5 gated by anti-bot challenges (see "Not downloaded" below).

Papers are grouped by domain for lookup. Entries show title, authors, year,
source venue, and either the local PDF filename or the original URL when the
source is paywalled / login-gated. The `[A]` / `[B]` tag indicates which pack
cited the paper.
